# Code of conduct

[日本語](docs/CODE_OF_CONDUCT.ja.md)

Drag'n Wash is a first-person washing game with a story: you play a kobold
who runs a wash service, and the three dragons who are your customers get to
know you as the levels go on. This repository is the framework the mods for it
are built on — a small, unhurried corner of the internet. Treat it as one.

## What is expected

- **Be kind, and assume the other person means well.** Nearly everyone here is
  doing this for fun, in a spare hour, often in a language that is not their
  first. Read the friendliest version of what they wrote.
- **Be patient with beginners.** "How do I even install BepInEx" is a fine
  question. So is a pull request that gets the branch wrong. Everyone writing
  mods today asked those questions once.
- **Keep criticism about the work.** "This hook runs every frame and it does
  not need to" is useful. "You clearly have no idea what you are doing" is not.
- **Take a hint.** If someone asks you to drop a topic or change how you are
  talking to them, drop it.

## What is not

- Harassment of any kind, in issues, pull requests, commit messages, code,
  translations or anywhere else this project reaches
- Insults or attacks about who someone is, rather than what they wrote —
  including about their nationality, language, ability, gender, sexuality,
  religion, age or appearance
- Unwanted sexual attention aimed at a person here. The game is an adult one
  and its text runs through this framework's Text and Dialogue libraries, so a
  line from it in an issue, a log or a test is ordinary work; a remark aimed at
  a contributor is not, and neither is bringing that register into a thread
  about something else
- Publishing someone's private information, or threatening to
- Sustained disruption: reopening settled arguments, spamming, deliberately
  wasting a reviewer's time

## Where this applies

Everywhere the project happens: issues, pull requests, discussions, commits,
the wiki, release notes, and any place where someone is speaking for this
project or its community.

## Reporting

If someone is out of line, tell the maintainer ([@TomXV](https://github.com/TomXV)).

- For anything you would rather not post in public, use the private form under
  the repository's **Security** tab —
  [**Report a vulnerability**](https://github.com/TomXV/dragnwash-modframework/security/advisories/new).
  It is meant for security reports, but it is the private channel this
  repository has, and it reaches the same person. Say at the top that it is a
  conduct report, not a security one.
- Anything else can be an ordinary issue.
- If the problem is with the maintainer, or you want someone else entirely,
  use GitHub's own [report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
  form. GitHub staff are not involved in this project.

Reports are read in private. You will get a reply. Depending on what happened,
the answer may be a quiet word, an edited or deleted comment, a closed thread,
or a block from the repository. Deliberately false reports are themselves a
breach of this document.
