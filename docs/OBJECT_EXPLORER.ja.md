# オブジェクトエクスプローラー（設計）

[English](OBJECT_EXPLORER.md)

> **設計のみで、まだ作っていません。** 2026-09-18 に `experimental/object-explorer` ブランチで作成。**Inspector** ライブラリ（[INSPECTOR.ja.md](INSPECTOR.ja.md)）の一部なので、これも実験的な機能で、開発者ツールの機能です（GUIDE のルール 8）。

Inspector が見せるのは **シーンの中にあるもの**、つまり Hierarchy、オブジェクト、そのコンポーネントです。ゲームが読み込んでいるものは、それだけではありません。テクスチャ、マテリアル、メッシュ、シェーダー、音、アニメーション、フォント、そして ScriptableObject に入ったゲーム独自のデータがあります。多くはシーンのどこかのオブジェクトにぶら下がっていますが、まとめて見る場所がありません。オブジェクトエクスプローラーは、その場所です。読み込まれているものすべてを種類別に並べます。Unity エディタの Project ウィンドウのようなものですが、中身は動いているゲームが読み込んでいるものです。

## 何のためで、何ではないか

- **調べる。** ゲームがどのテクスチャや音を読み込んでいるか、ゲームのデータを持つ ScriptableObject に何が入っているか、マテリアルがどのシェーダーを使っているか、そして**それぞれがどこで使われているか**。
- **試す。** Inspector の行と同じ編集を、これらのオブジェクトにもできます。保存はしません。
- **書き出しはしません。** アセットをファイルに書き出すのは[アセットツール](ASSET_TOOL.ja.md)の 3 番目の段階で、そちらに残します。
- **差し替えはしません。** プレイヤーに届くマテリアルの差し替えは Assets ライブラリの仕事で、テクスチャの差し替えの隣に、後で別に設計します。
- オブジェクトの作成・複製・削除、アセットバンドルの読み込み、音の再生は、最初の版には入れません。

## タブ

Inspector のツールバーに **Scene | Objects** の切り替えを足します。**Scene** は今のタブのままです。**Objects** では、左の欄がエクスプローラーになります。右側は今の中身の欄のままなので、その欄でできること（行、編集、Reset、History、Code）がここでも使えます。

### 左の欄：種類とオブジェクト

種類ごとのフォルダーを、件数つきで並べます。

| フォルダー | 入るもの |
|---|---|
| Textures | `Texture2D`、`RenderTexture`、`Cubemap` などの `Texture` |
| Sprites | `Sprite` |
| Materials | `Material` |
| Shaders | `Shader` |
| Meshes | `Mesh` |
| Audio | `AudioClip` |
| Animation | `AnimationClip`、`RuntimeAnimatorController` |
| Fonts | `Font`、`TMP_FontAsset` |
| Data | `ScriptableObject`。型ごとのサブフォルダーに分ける（ゲーム独自の型を先に） |
| Objects outside the scenes | 読み込まれたどのシーンにも属さない `GameObject`（ゲームが読み込んだままにしているプレハブや雛形） |
| Other | それ以外。型ごと |

- フォルダーを開くと、オブジェクトが並びます。名前と、種類ごとの短い情報をひとつ出します（テクスチャならサイズ、メッシュなら頂点数、クリップなら長さ）。
- **Search** の欄は、Scene で Hierarchy を絞り込むのと同じように、開いているフォルダーを名前で絞り込みます。種類の指定（Unity エディタと同じ `t:Material`）で、1 つの種類だけを探せます。
- 名前のないオブジェクトは、型と一緒に `(no name)` と出します。
- Unity が隠しているオブジェクト（`HideFlags.HideAndDontSave` など）は、**Show hidden** をオンにしたときだけ出します。既定はオフです。
- 行を描くのは画面に見えている部分だけにします。何万件あるフォルダーでも、短い一覧と同じようにスクロールできます。

### 右の欄：選んだオブジェクト

今の中身の欄を、どのオブジェクトにも使います。公開のフィールドとプロパティを出し、非公開のものは **Show private** の後ろに置きます。操作もエラーの扱いも今と同じです。その上に、種類ごとの短い見出しを付けます。

| 種類 | 見出し |
|---|---|
| テクスチャ、スプライト | すでに読み込まれているテクスチャのプレビュー、サイズ、形式、CPU から読めるか、ミップマップ。Assets タブへの **Go**（Mod が同梱した差し替えはそちらに出る） |
| マテリアル | 今の Inspector がマテリアルに出しているもの（シェーダーのプロパティとキーワード、共有している Renderer の数） |
| シェーダー | プロパティとキーワード、使っているマテリアルの数 |
| メッシュ | 頂点数・三角形数・サブメッシュ数、範囲（bounds）、読めるかどうか |
| AudioClip | 長さ、チャンネル数、周波数、読み込みの状態 |
| AnimationClip | 長さ、フレームレート、イベント |
| ScriptableObject | 追加なし。フィールドそのものが見どころで、コンポーネントと同じように行になる |
| シーン外の GameObject | コンポーネント。読み取り専用（[編集](#編集)を参照） |

### Used by（どこで使われているか）

見出しの **Used by** ボタンで、選んだものが使われている場所を一覧にします。たくさんのオブジェクトを調べるので、ボタンを押したときだけ動きます。

| 選んだもの | 探す場所 |
|---|---|
| マテリアル | Renderer の `sharedMaterials`、UI の `Graphic.material` |
| テクスチャ | マテリアルのテクスチャのプロパティ、スプライト、UI の `RawImage` |
| スプライト | `SpriteRenderer`、UI の `Image` |
| シェーダー | マテリアル |
| メッシュ | `MeshFilter`、`SkinnedMeshRenderer`、`MeshCollider`（コライダーの形と同じくリフレクションで読む） |
| AudioClip | `AudioSource.clip` |
| AnimationClip | `RuntimeAnimatorController.animationClips`、`Animation` |
| フォント | `TMP_Text.font`、UI の `Text.font` |
| ScriptableObject、その他 | シーンのコンポーネントのうち、それを持っているフィールド（コンポーネントの型ごとにフィールドをリフレクションで調べ、型ごとにキャッシュ。見つかった数が数千で打ち切り） |

見つかったものは 1 行ずつ出します。クリックすると、シーンのオブジェクトなら **Scene** に切り替えてそれを選び、マテリアルやアセットなら Objects でそれを選びます。上限で打ち切ったときは、一覧にそう出します。

### Scene との行き来

- 中身の欄の `UnityEngine.Object` の行（テクスチャ、メッシュ、クリップ、ScriptableObject など）には、今 Inspector が知っている種類に限らず、すべてに **Go** を付けます。シーンの外にあるものの Go は、Objects で開きます。
- `Inspector.Inspect(UnityEngine.Object)` は、どのオブジェクトでも受け付け、合う表示で開きます。
- テクスチャから Assets タブへの Go はそのまま残します。Assets タブでテクスチャの **Inspect** を押すと、Objects で開きます。

## 編集

Scene と同じ行、同じ規則です。足すのは 2 つです。

- **共有されているもの。** アセットはふつう、たくさんのオブジェクトから使われています。マテリアル、テクスチャのフィルターモード、ScriptableObject の値を変えると、それを使っている所すべてが変わります。**Used by** を実行したあとは、見出しに使っている数を出します。また、共有されているアセットを最初に編集したときに、1 回だけそのことを知らせます。
- **シーンの外にあるオブジェクトは読み取り専用。** ゲームが読み込んだままのプレハブを変えると、そこから後で作られるものすべてが変わり、気づきにくく、元に戻しにくいからです。行は表示しますが、編集はできません。本当に必要になったら、専用の警告つきのスイッチにします。

編集は Scene と同じく **History** に入り、Revert と Redo ができます。ファイルには何も書きません。

## 一覧の作り方

- `Resources.FindObjectsOfTypeAll<UnityEngine.Object>()` を 1 回たどり、フォルダーに振り分けます。動くのは、Objects を初めて開いたとき、**Refresh** を押したとき、一覧にまだない種類で絞り込んだときです。毎フレームは動かしません。
- **一覧がアセットを生かし続けてはいけません。** Unity の `Resources.UnloadUnusedAssets` は、マネージドコードが参照しているアセットを解放しません。参照の一覧を持つと、ゲームが次の場面に進んだあとも、前のシーンのアセットがメモリに残ってしまいます。
  - そのため一覧には、インスタンス ID、名前、短い情報だけを持ちます。オブジェクトを探し直すのは、選んだときとプレビューを描くときだけです。
  - ID からオブジェクトを探す方法がこの Unity（6.3）にあるかは、実装のときに確かめます。
  - 公開の方法がなければ、参照は Objects を開いている間だけ持ちます。タブを閉じたときやシーンが解放されたときに手放し、**Refresh** を押すまで「一覧が古い」と表示します。
- シーンを読み込むと、一覧に「古い」の印を付けます（Hierarchy と同じイベント）。見に来るまで作り直しません。
- 選んでいたオブジェクトを Unity が破棄したときは、Scene と同じく、メモを出して選択を外します。

## 安全

- **開発者ツールのときだけ。** Inspector のほかの部分と同じです。
- **アップロードなし。** プレビューは、ゲームがすでに読み込んだテクスチャを描くだけです。作成・読み戻し・アップロードはしないので、Direct3D 12 の問題は起きません。GPU だけが持っているテクスチャも、読まずにそのまま描きます。
- **名前はウィンドウの保護を通して描く。** Tool window のほかの場所と同じです。
- **失敗はその行にとどめる。** プロパティの getter が例外を出しても（Unity のオブジェクトには、当てはまらないプロパティで例外を出すものがあります）、その行に出して一覧は続けます。
- **重い処理は押したときだけ。** 一覧、Used by、プレビューは、ボタンを押したときか選んだオブジェクトにだけ動きます。Objects を閉じて遊んでいる間の負担はありません。

## コンソール

- `objects` でフォルダーと件数を表示します。`objects <種類> [絞り込み]` で合うオブジェクトを並べます（例：`objects Material counter`）。
- `inspect object <種類> <名前>` で、Objects のオブジェクトを選びます。
- `objects usedby <種類> <名前>` で、Used by の一覧を表示します。

## 作る順番

1. Scene | Objects の切り替え。種類別の一覧と件数、検索と `t:`。今の中身の欄での表示（最初は読み取り専用）。Scene の行からすべての種類への Go。`Inspector.Inspect` をどのオブジェクトでも使えるように。
2. 種類ごとの見出しと、テクスチャ・スプライトのプレビュー。
3. Used by。
4. 共有の知らせつきの編集と History。
5. コンソールのコマンド。
6. Show hidden と、ScriptableObject の型ごとのサブフォルダー。

後で考えるもの（この設計には入れない）：音の再生、書き出し（アセットツールの 3 番目）、Mod に同梱するマテリアルの差し替え（Assets ライブラリ）。
