After a game update, add the new build's files to `ci/game-fingerprints.json` with `tools/game-fingerprints.py` (on Windows, on the Steam Deck and on a Mac), so CI keeps refusing the game's files. / ゲームがアップデートされたら、`tools/game-fingerprints.py` で新しいビルドのファイルを `ci/game-fingerprints.json` に追加してください（Windows、Steam Deck、Mac のそれぞれで）。CI がゲームのファイルを拒否し続けられます。
