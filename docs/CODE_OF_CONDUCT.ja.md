# 行動規範

[English](../CODE_OF_CONDUCT.md)

Drag'n Wash は、物語のある一人称の洗浄ゲームです。プレイヤーは洗い場を切り盛りする
コボルドで、お客である 3 匹のドラゴンとは、レベルが進むにつれて親しくなって
いきます。このリポジトリは、その Mod が乗るフレームワークです。
インターネットの小さくてのんびりした一角として扱ってください。

## お願いしたいこと

- **親切に。相手には悪気がないと考えて。** ここにいるほぼ全員が、空いた時間に、
  楽しみでやっています。母語でない言葉で書いている人も多い。書かれたものは、
  いちばん好意的に読めるかたちで読んでください。
- **はじめての人には気長に。** 「そもそも BepInEx はどう入れるの」はちゃんとした
  質問です。ブランチを間違えたプルリクエストもそう。いま Mod を書いている人は
  みんな、一度はそれを聞きました。
- **批判は作ったものに向けて。** 「このフックは毎フレーム走っているけれど、その
  必要はない」は役に立ちます。「どう見ても分かっていませんね」は役に立ちません。
- **引き際を受け取る。** その話はやめてほしい、その言い方はやめてほしいと言われ
  たら、やめてください。

## やめてほしいこと

- あらゆる嫌がらせ。Issue、プルリクエスト、コミットメッセージ、コード、訳文、
  そのほかこのプロジェクトが届くどこであっても
- 書いたものではなく、その人自身に向けた侮辱や攻撃。国籍・言語・能力・性別・
  性的指向・信条・年齢・容姿についてのものを含みます
- 人に向けた、望まれていない性的な言動。ゲームは成人向けで、その文字列はこの
  フレームワークの Text や Dialogue ライブラリを通ります。ですから Issue や
  ログやテストにその手の台詞が出てくるのは普通の作業です。協力者本人に向けた
  発言はそうではありませんし、関係のないスレッドにその調子を持ち込むのも同じ
  です
- 誰かの私的な情報を公開すること、またその示唆
- 場を壊し続けること。決着した議論の蒸し返し、スパム、レビューする人の時間を
  わざと浪費すること

## 適用される範囲

このプロジェクトが動くところすべてです。Issue、プルリクエスト、Discussions、
コミット、Wiki、リリースノート、そして誰かがこのプロジェクトやその参加者を代表
して話している場所。

## 報告

誰かの振る舞いがおかしいときは、メンテナー（[@TomXV](https://github.com/TomXV)）に
知らせてください。

- 公開の場に書きたくないことは、このリポジトリの **Security** タブの非公開の
  フォーム（[**Report a vulnerability**](https://github.com/TomXV/dragnwash-modframework/security/advisories/new)）
  を使ってください。本来はセキュリティ報告のためのものですが、このリポジトリに
  ある非公開の窓口はこれで、届く先は同じ人です。冒頭に、セキュリティではなく
  行動についての報告だと書いてください。
- それ以外は普通の Issue で構いません。
- 問題がメンテナー自身にあるとき、あるいはまったく別の人に見てほしいときは、
  GitHub 自身の[不適切な行為の報告](https://docs.github.com/ja/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
  を使ってください。GitHub の担当者はこのプロジェクトとは無関係です。

報告は非公開で読みます。返事はします。何が起きたかによって、答えは一言の注意で
あったり、コメントの編集や削除、スレッドを閉じること、リポジトリからのブロック
であったりします。わざと嘘の報告をすることも、この文書に反します。
